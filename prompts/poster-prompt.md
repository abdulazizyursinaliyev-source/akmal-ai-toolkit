# Poster / Marketplace Kartochka Skill

Mahsulot suratini sotadigan poster/creative'ga aylantirish uchun JSON prompt tizimi (Uzum, Wildberries, Ozon, Instagram uchun).

## 5 qadam

1. Mahsulotni o'qish (nima, rang, brend)
2. Savol berish (headline, specs)
3. Layout tanlash
4. Copy yozish (1-3 so'z headline + spec chips)
5. JSON output + mahsulot surati birga model'ga beriladi

## Qat'iy qoidalar

- Mahsulotni redizayn qilmaslik
- Soxta sertifikat/discount qo'shmaslik
- Text max 25 so'z
- Max 4 rang
- Text mahsulot ustiga tushmasin

## Model tavsiyalar

- Nano Banana / Gemini - eng yaxshi mahsulot aniqligi
- ChatGPT - eng yaxshi text imlosi
- Midjourney - faqat clean-plate dizayn
