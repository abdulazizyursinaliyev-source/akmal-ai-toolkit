# Hissa qo'shish

Rahmat! Bu toolkit amaliy ish uchun — har bir hissa sinovdan o'tgan bo'lishi kerak.

## Nima qo'shish mumkin

- **Prompt** — `prompts/` ga. Tuzilma: formula → tayyor shablon (`[...]` joylari bilan) → misol → tekshiruv ro'yxati.
- **Shablon** — `templates/` ga. GSAP shabloni `window.__seek(t)`, `window.__duration`, `window.__ready` ni e'lon qilishi shart (render uchun).
- **Skill** — `skills/<nom>/SKILL.md`. Frontmatter: `name`, `description` (qachon ishlatilishi).
- **Natija misoli** — `examples/` ga oldin/keyin (faqat o'zingiz yaratgan, huquqi sizda bo'lgan material).

## Qoidalar

1. Promptlar inglizcha, tushuntirishlar o'zbek lotin yozuvida.
2. Dizayn — `templates/brand-tokens.css` tokenlari. Yangi rang qo'shilmaydi.
3. Soxta da'vo, sertifikat, mijoz fikri yo'q. Mashhur brend/personajdan nusxa yo'q.
4. Skript yoki shablon — PR'da qanday sinaganingizni yozing (buyruq + natija).

## Jarayon

1. Fork → yangi branch (`feat/hook-asmr`).
2. O'zgartirish + sinov.
3. Pull request — qisqa tavsif va (vizual bo'lsa) screenshot yoki GIF.
